# Créditos

## Arte

Todo el arte del repositorio (heroínas, proyectil, tilesets, autotiles y objetos) es original y se genera con los scripts de `tools/generadores/`. No incluye assets de terceros.

Las ilustraciones usadas como referencia durante el diseño sirvieron solo para marcar el tono y no forman parte del proyecto.

## Assets de terceros
